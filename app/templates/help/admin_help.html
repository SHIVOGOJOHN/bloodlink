Admin — How to use BloodLink

Guidance for administrators and support staff.

Overview

Admins manage users, review audit logs, and ensure the system runs smoothly. Use the admin dashboard to see recent activity and training runs.

Training and forecasts

You can review forecast training runs and artifacts. If you upload training data, verify the provenance and confirm it was mirrored to the repository.

Support

For support requests, gather the user's role, the time of the issue, and any relevant screenshots. Use the admin tools to inspect database records if needed.
