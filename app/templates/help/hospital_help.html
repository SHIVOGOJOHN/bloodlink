Hospital staff — How to use BloodLink

This page explains what you see and how to use it. Read slowly — everything you need is here.

Overview

BloodLink helps your hospital request blood, view local stock, and plan for future demand. The dashboard shows your active requests, nearby blood banks, and a suggested forecast of future needs.

Dashboard sections

My requests

This lists the blood requests you have created. Each request shows the blood type, how many units you asked for, the urgency, and whether it has been fulfilled. To create a new request, use the form at the top of the dashboard.

Local stock

This shows the available units of each blood type in nearby blood banks. Use this to see if a nearby bank can fulfill your request. If a bank can cover the request, contact them directly using the contact details shown in the stock entry.

Matching donors

For open requests, we show a list of potential donors who match the required blood type and are likely available. This is just a convenience; contact donors using the provided details and follow normal clinical procedures.

Forecast panel

The forecast panel shows an estimate of how many units your hospital might need over the coming days. - "Total predicted units" is the sum expected across the forecast window. - "Average daily" is how many units per day we expect on average. - "Peak units" shows the highest single-day demand in the window. - The forecast also highlights the blood types likely to be most needed.

Driver explanations

We show a short explanation describing why the forecast looks the way it does. This uses simple terms: - "Drivers" are things that most affect demand (for example, recent requests or low stock in the county). - If a driver says "higher", it means that factor pushes demand up; "lower" means it pulls demand down.

Uploading training data

If you have historical request data in a CSV file, use the "Upload training CSV" button in the forecast panel. This improves the forecasting model. The app will ignore duplicate rows and will mirror the CSV to your project repository if configured.

Manual forecast run

If you want the latest forecast right now, click "Run forecast now". This retrains the model and updates the dashboard.

Practical tips

  • Always double-check the units before accepting a transfer.
  • When creating a request, be precise about urgency—this helps the system prioritize.
  • Use the forecast to plan for the next two weeks, but always confirm availability with blood banks.

Questions or support

For help, contact your regional BloodLink administrator or use the contact form in the app. If something seems wrong with the data, note the date and the affected entries when you ask for help.
